# Portfolio Website

Personal portfolio website showcasing my projects, technical writeups, and experience.

## Overview
This is a lightweight static site built to present my work in software engineering, automation, Linux, networking, and systems-oriented projects.

## Stack
- HTML
- CSS

## Structure
- `index.html` — homepage
- `writeups/` — technical writeups and case studies
- `images/` — screenshots and diagrams
- `styles.css` — site styling

## Local Preview
Open `index.html` in a browser, or serve the project with a simple local static server.
